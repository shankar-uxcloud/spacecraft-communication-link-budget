# Spacecraft Communication Link Budget and Antenna Study

## Project Overview

This repository contains the educational work completed for the YuvaIntern Spacecraft Communications Internship. The project studies a notional spacecraft-to-Earth radio-frequency (RF) telemetry downlink, focusing on link-budget calculations, antenna characteristics, protocol selection, and validation.

## Objectives

- Understand the fundamentals of spacecraft communication and RF link budgets.
- Estimate free-space path loss, antenna gain, received power, and link margin using documented assumptions.
- Study antenna concepts and their impact on communication performance.
- Examine relevant CCSDS standards and validate calculations against reliable references.
- Document the methodology, assumptions, limitations, and results transparently.

## Important Notes

This is a preliminary educational study using a notional mission scenario. Any assumed parameters will be identified clearly. Calculations and simulation results will not be represented as actual spacecraft measurements, flight-qualified design results, or regulatory approval.
